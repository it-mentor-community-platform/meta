# Бизнес аналитика - профили

Профиль участника сообщества включает в себя:
- Имя, фамилия, ссылка на профили в Telegram, Github
- Роль
- Достижения (achievements)
- Проекты и ревью

## Функционал

- Редактирование своего публичного профиля
- Просмотр чужих публичных профилей
- Поиск профилей по имени/гитхабу/телеграму

## Личная информация

В скобках указаны названия полей.

- Имя (`first_name`) и фамилия (`last_name`). Инициализируются по значениям из Telegram init data, доступны для редактирования. После того как пользователь отредактировал имя в профиле, значения из Telegram его больше не перезаписывают.
  - Имя обязательно при редактировании, фамилия необязательна (может быть очищена). Значения обрезаются по краям, не длиннее 64 символов (как в Telegram).
  - Имя может отсутствовать - например, у профиля, импортированного из Google таблицы, владелец которого ещё не открывал Mini App. В этом случае вместо имени показывается `@username` из Telegram, а если его нет - GitHub username.
- Ссылка на телеграм профиль в формате `https://t.me/${:username}` (`telegram_url`). Инициализируются и актуализируются по значению из Telegram init data, недоступны для редактирования. Username в Telegram необязателен, поэтому ссылки может не быть - тогда она появится после того, как пользователь задаст username в Telegram и откроет Mini App.
- GitHub profile url в формате `https://github.com/${:username}` (`github_profile_url`). Инициализируется при сдаче первого проекта, если ещё не был установлен. Доступен для редактирования. Один GitHub аккаунт может быть привязан только к одному профилю - при попытке указать уже привязанный аккаунт пользователь видит ошибку.
 
Свой профиль показывает только имя, роли и контакты (с редактированием) и кнопку "Поделиться профилем". Прогресс и сданные проекты пользователь видит на странице "Мои проекты", поэтому в своём профиле они не дублируются.

## Публичный профиль

Ссылка на профиль строится по идентификатору профиля (`id`). Два формата:
- сайт: `/profiles/<id>` от адреса приложения, например `/profiles/42`
- Mini App: диплинк `startapp=profile_<id>`, например `https://t.me/<bot>?startapp=profile_42`

Свой профиль можно отправить кнопкой "Поделиться профилем": в Mini App - через Telegram (диплинк), на сайте - копированием ссылки на сайт. Профили не удаляются, поэтому ссылка на профиль не устаревает.

Состав публичного профиля:
- Имя и фамилия, роли
- Ссылки на Telegram и GitHub
- Прогресс по роадмапам (Java, Python, Go) - по тем же правилам, что и на странице "Мои проекты" ([student-roadmap-completion.md](./student-roadmap-completion.md))
- Список сданных проектов роадмапа: тип проекта и реализации (язык, ссылка на GitHub репозиторий)

## Достижения (achievements)

Элемент геймификации. Аналогия - ачивки в играх.

Пользователь может получать ачивки, выполняя определённые действия - сдавать проекты, делать ревью. Полученные ачивки пользователь может по желанию отобразить в профиле.

### Виды ачивок

За проекты:
- "Первый проект" - за сдачу первого (любого, не обязательно виселицы) проекта данным пользователем
- "Все проекты" - за сдачу всех проектов с 1 по 6 в любом порядке и на любых языках
- "Билингв" - за сдачу проектов на 2 языках
- "Полиглот" - за сдачу проектов на 4+ языках
- "Спринтер" - сданы проекты с 1 по 6. Разница между таймстампами сдачи первого и шестого проектов - меньше чем 6 месяцев 

За ревью:
- "Будущий ментор" - за сдачу первого ревью
- "Универсальный ревьюер" - за сдачу ревью на проекты более чем 4 разных типов (виселица, симуляция, ...)
- "Опытный ревьюер" - за сдачу 25 ревью или более
- "Столп сообщества" - за сдачу 100 ревью или более
