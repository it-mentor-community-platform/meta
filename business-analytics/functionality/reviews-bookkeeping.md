# Бизнес аналитика - учёт проектов

## Необходимый контекст

- Google Spreadsheet [таблица](https://docs.google.com/spreadsheets/d/1E66YrdvO7B_j0Ykge-JJDMtB1RfKhIzN_SsO7UPDbrU/edit?gid=0#gid=0), лист "projects". Пополняется вручную

## Способы добавления ревью

- Через интерфейс Telegram mini ap
- Импорт из Google таблицы

## Хранилище ревью

- SQL база проекта
- Google таблица

Подразумевается поддержка обоих хранилищ. SQL - для функционала проекта, таблица - для совместимости с уже существующим функционалом по учёту проектов и генерации [списка ревью](https://zhukovsd.github.io/java-backend-learning-course/finished-projects/) на сайте роадмапа.

## Реакция системы на добавленный проект

- Добавление проекта в БД, к которой будут обращаться клиентские API, работающие с проектами
- Оповещение членов чата @zhukovsd_it_chat
- Оповещение студента о ревью на его проект
- Добавление проекта в Google таблицу
- Любая бизнес логика, завязанная на новое ревью - пересчёт бейджей ("ачивок") пользователя, например за количество ревью
